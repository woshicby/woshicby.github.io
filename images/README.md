# images 图片目录

网站所有图片资源。

## 子目录约定

| 目录 | 用途 | 命名规范 |
|------|------|---------|
| `post.<N>.<日期>/` | 博文配图 | 按博文编号分目录 |
| `moments/` | 灵感碎片图片 | `YYYYMMDD_HHMMSS.jpg`(时间戳) |
| `tickets/` | 票据照片 | `日期_标题_序号.jpg` |
| `finisher_certificates/` | 完赛证书 | — |
| 根目录散图 | 站点级资源 | favicon/导航图标/背景等 |

## 规范

- 博文配图:相对路径引用 `./images/post.N.日期/xxx.jpg`
- 灵感碎片图:时间戳命名,与 moments.json 的 created_at 对应
- 票据图:重命名后跑 `票据图片更新.command` 重新生成映射
- 新增图片注意控制体积(视频/大图超 100MB 无法推 GitHub,需压缩)

## 注意

- 站点级资源(图标/背景)直接放根目录,不建子目录
- 引用关系:删图前确认无博文/JSON 引用(防 404)
